# Kriyana Shop Website

A modern, responsive e-commerce website for a grocery store built with HTML, CSS, and JavaScript.

## Features

✨ **Product Catalog**
- 20+ grocery products including rice, flour, vegetables, fruits, dairy, and more
- Product prices and quantity selector
- Easy-to-use product grid layout

🛒 **Shopping Cart**
- Add/remove items from cart
- Real-time cart total calculation
- Item quantity management
- Persistent cart storage (saves even after page refresh)

📱 **Responsive Design**
- Mobile-friendly interface
- Optimized for all screen sizes
- Smooth animations and transitions

🎨 **User-Friendly Interface**
- Green color theme (fresh & natural)
- Smooth navigation
- Product search and browsing
- Quick checkout process

## How to Use

1. **Browse Products**: Scroll through the product grid and select items you want to purchase
2. **Add to Cart**: 
   - Enter the quantity you want
   - Click "Add to Cart" button
   - You'll see a green notification confirming the item was added
3. **View Cart**: Click the "🛒 Cart" button in the navigation bar to view your items
4. **Remove Items**: Click "Remove" button in the cart to delete items
5. **Checkout**: Click "Checkout" button to complete your purchase

## Customization

To customize the website:

1. **Change Shop Name**: Edit the logo text in `index.html`
2. **Add Products**: Add new items to the `products` array in `script.js`
3. **Change Colors**: Modify CSS variables in `style.css`:
   - `--primary-color: #2ecc71` (Green)
   - `--secondary-color: #27ae60` (Dark Green)
4. **Update Contact Info**: Edit the contact section in `index.html`
